# Doppler skills

Install the Doppler skills into this repo before writing or changing any Doppler code:

```bash
npx skills add whetstoneresearch/doppler-skills -a claude-code
```

The command places the skill folders next to this file. The ones this starter leans on are `pda-multicurve` (curve shares, the max tail, the locked deployment mode), `fee-architecture` (beneficiaries, protocol owner minimum, integrator accounting) and `verification` (checking a launch on chain). The skills are MIT licensed by Whetstone Research.
